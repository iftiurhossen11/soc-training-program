# Module 2: Network Security & Traffic Analysis - Study Materials

This folder contains theoretical notes, protocol references, and study guides for analyzing network traffic and identifying security threats.

## 📚 Topics Covered in this Module:
- **Network Fundamentals:** OSI Model, TCP/IP Stack.
- **Core Protocols:** TCP, UDP, HTTP/HTTPS, DNS, ARP, ICMP.
- **Traffic Analysis Concepts:** Baselines, Indicators of Compromise (IoCs), and Packet structures.
- **Tools Overview:** Deep dive into Wireshark display filters and tcpdump commands.
