# Module 7: AI/ML in SOC - Study Materials

This folder contains research papers, articles, and study resources related to the application of AI/ML in cybersecurity and SOC operations.

## 📚 Comprehensive Study Topics

### 1. Machine Learning Algorithms for Security
- **Decision Trees & Random Forests:** Used for malware classification.
- **Clustering (K-Means, DBSCAN):** Used for anomaly detection in network traffic.
- **Neural Networks (Deep Learning):** Used for advanced pattern recognition and image-based malware analysis.

### 2. AI in Threat Intelligence
- Using NLP to parse unstructured threat reports and extract IoCs automatically.
- Predictive intelligence: Forecasting potential future attacks based on historical data.

### 3. Python for SOC Automation
- Libraries to know: `pandas` (data manipulation), `scikit-learn` (ML models), `requests` (API calls), `splunk-sdk` (Splunk automation).
- Automating log parsing and enrichment.

### 4. Capstone Project Resources
- **Datasets:** 
  - CIC-IDS2017/2018
  - MalwareBazaar (for malware samples)
  - VirusTotal API (for threat intel)
- **Report Writing Templates:** Standard Incident Response report structures (Executive Summary, Timeline, Root Cause, Recommendations).
