# Module 3: SIEM & Log Management

## 🎯 Module Objective
To understand how Security Information and Event Management (SIEM) systems work, how to collect and parse logs, and how to create alerts to detect security incidents.

## 📝 Study Notes

### 1. What is SIEM?
- **SIEM** stands for Security Information and Event Management.
- It collects log data from various sources (Firewalls, Windows, Linux, Applications) and correlates them to detect anomalies.
- **Key Components:** Log Collection, Parsing, Normalization, Correlation, Alerting, and Dashboards.

### 2. Common Log Sources
- **Windows Event Logs:** Security (4624, 4625), System, Application.
- **Linux Logs:** Syslog, Auth.log.
- **Network Logs:** Firewall, IDS/IPS, Web Proxies.
- **Cloud Logs:** AWS CloudTrail, Azure Activity Logs.

### 3. SIEM Tools
- **Splunk:** Industry standard for log analysis.
- **Elastic Stack (ELK):** Open-source alternative.
- **Wazuh:** Open-source SIEM and XDR.
