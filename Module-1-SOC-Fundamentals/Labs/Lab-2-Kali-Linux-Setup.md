# Lab 2: Kali Linux VM Creation & Basic Configuration

## 🎯 Objective
To deploy and boot a Kali Linux Virtual Machine which will act as the "Attacker" or "Simulated Threat Actor" machine in our SOC lab environment. This VM will be used in future modules to generate malicious network traffic and attacks for detection testing.

## 🛠️ Tools & Environment Used
- **Operating System:** Kali Linux (Version: 2024.x)
- **Hypervisor:** Oracle VirtualBox
- **Allocated Resources:** 8GB RAM, 6 CPUs

## 📝 Detailed Lab Steps & Execution

### Step 1: Booting the VM
1. Selected the Kali Linux VM from the VirtualBox Manager and clicked "Start".
2. The VM successfully booted into the GRUB bootloader and loaded the Kali Linux kernel.

### Step 2: Reaching the Login Screen
1. Verified that the Kali Linux login screen (Display Manager) loaded successfully.
2. Confirmed the system is ready for user authentication and logged in.

### Step 3: Terminal Verification
1. Opened the terminal to verify system functionality.
2. Ensured the environment is ready for executing offensive security tools in future labs.
