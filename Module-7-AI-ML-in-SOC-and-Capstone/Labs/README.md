# Module 7: AI/ML in SOC & Capstone - Labs

This folder contains the practical labs and the final Capstone Project for Module 7.

## 🧪 Lab Index

*   **Lab 1: Automating Threat Intel with Python**
    *   *Objective:* Write a Python script that takes a list of IP addresses, queries the VirusTotal API, and outputs a report on their reputation.
*   **Lab 2: Introduction to Machine Learning for Log Analysis**
    *   *Objective:* Use Python (`pandas` and `scikit-learn`) to analyze a dataset of network traffic and use an Isolation Forest algorithm to detect anomalies (e.g., port scans).
*   **Lab 3: Implementing a Basic SOAR Playbook**
    *   *Objective:* Simulate a SOAR playbook (using a tool like n8n, Shuffle, or a simple Python script) that triggers when a suspicious login is detected, creates a ticket, and sends an alert to a Slack/Discord channel.
*   **Lab 4: Capstone Project Execution**
    *   *Objective:* Execute the chosen Capstone Project (e.g., Build a Mini-SOC, perform a deep malware analysis, or conduct a threat hunt).
*   **Lab 5: Capstone Project Presentation**
    *   *Objective:* Document the Capstone project findings in a professional report and prepare a summary presentation.
