# Module 6: Threat Hunting & CTI - Labs

This folder contains hands-on labs for proactive threat hunting and threat intelligence gathering.

## 🧪 Lab Index

*   **Lab 1: Intelligence Gathering with Open-Source Tools (OSINT)**
    *   *Objective:* Use tools like VirusTotal, AlienVault OTX, and Shodan to investigate a suspicious IP address or domain.
*   **Lab 2: Writing and Testing a YARA Rule**
    *   *Objective:* Create a basic YARA rule to detect a specific malware family based on its strings and test it against a sample file.
*   **Lab 3: Writing Sigma Rules for SIEM Detection**
    *   *Objective:* Write a Sigma rule to detect suspicious PowerShell execution and convert it into a Splunk search query.
*   **Lab 4: Hypothesis-Driven Threat Hunt in Splunk**
    *   *Objective:* Assume an attacker is using "Living off the Land" binaries. Hunt for unusual use of `certutil.exe` or `whoami.exe` in the SIEM logs.
*   **Lab 5: Mapping an Attack to MITRE ATT&CK**
    *   *Objective:* Take a real-world threat report (e.g., from Mandiant or CrowdStrike) and map the adversary's behavior to the MITRE ATT&CK Navigator.
