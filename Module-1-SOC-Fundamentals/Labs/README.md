# Module 1: Home Lab Setup & Fundamentals - Labs

This folder contains the hands-on lab exercises and reports for Module 1. The primary goal is to build an isolated virtual environment for security testing and monitoring.

## 🧪 Lab Index

*   **Lab 1: VirtualBox Installation & Configuration**
    *   *Objective:* Install the hypervisor and configure basic settings.
*   **Lab 2: Windows 10/11 VM Creation**
    *   *Objective:* Deploy the primary victim machine for future endpoint monitoring.
*   **Lab 3: Kali Linux VM Creation**
    *   *Objective:* Deploy the attacker machine for network traffic generation.
*   **Lab 4: Network Isolation Setup**
    *   *Objective:* Configure a Host-Only/Internal network to ensure safe malware analysis.
*   **Lab 5: Snapshot Management**
    *   *Objective:* Learn to take, revert, and manage VM snapshots to maintain a clean state.


*Note: Detailed lab reports with step-by-step instructions and screenshots will be added as they are completed.*
